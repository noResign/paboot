## 0. 一句话

**深夜的驾驶舱，极光落在玻璃上。** 界面是安静的、有深度的、发着微光的；数据精确、动作轻，
用久了不累。

- **科幻**来自：深空底色、玻璃层次、极光当「光源」、等宽字的数据感、精确的细线。
- **治愈**来自：低饱和、低纯黑/纯白、暖光点缀、充足留白、短而柔的动效。
- **高级**来自：克制——一屏只有一个视觉焦点，其余全部退后。

> 桌面端默认皮肤是 **品牌**：品牌青绿主按钮、中性灰面、发丝边，安静克制、像原生桌面工具（§2.1）；
> 用户可切换其他内置皮肤，但极光 / 玻璃只属于移动端语言。

## 1. 设计立场：科幻与治愈如何共存

两者天然拉扯（科幻偏冷、治愈偏暖），用三条线调和，并设一条硬约束：

| 线 | 作用 | 具体 |
|---|---|---|
| **深空**（底） | 氛围、纵深 | 近黑蓝底、抬升面板、极淡描边；不追求纯黑 |
| **极光**（光） | 科幻、焦点 | 青→蓝→紫的渐变**只当光源**：光晕、运行脉冲、主按钮的辉光 |
| **暖光**（人） | 治愈、温度 | 琥珀暖色只给「完成 / 人类相关 / 温柔提示」，与冷色形成呼吸 |

**硬约束（克制原则）**：

1. **一屏一个光晕（移动端）。** 极光 bloom 每屏最多一处，放在该屏唯一的焦点后面（连接页 hero、
   运行中的会话、主 CTA）。其余位置一律不用；桌面基础层不用 bloom（可选氛围特效走 `fx` 层，默认关）。
2. **渐变不上面积。** 极光渐变只用于：细线、按钮辉光、焦点光晕、hero 背景。**禁止**给整块卡片、
   整页背景、正文区域铺渐变。
3. **玻璃只在浮层（移动端）。** 毛玻璃只用于「漂浮的功能层」——Tab 栏、滚动后的顶栏、输入框、
   Sheet、弹出层。内容卡片永远不用玻璃，也**不玻璃叠玻璃**；桌面基础层不用毛玻璃（特效走 `fx` 层）。
4. **彩色面积守恒。** 一屏内高饱和色（primary / 暖光 / 状态色）的面积不超过约 10%，其余是中性色。
5. **动效一次一个。** 同一视图内最多一个持续动效（运行脉冲或思考微光），其余交互只在操作瞬间动。

## 2. 双主题策略

两套都是一等公民，跟随系统 + 手动切换（桌面为显式三态：浅 / 深 / 跟随）。

| 主题 | 定位 | 用色倾向 |
|---|---|---|
| **深空（深色，旗舰）** | 品牌面貌、演示与默认审美 | 近黑蓝底 + 抬升面板 + 冷光；暖色点缀 |
| **晨光（浅色）** | 白天与长时间阅读 | 冷雾白底 + 白面 + 柔光阴影；极光降饱和、仅作点缀 |

规则：

- 两套**语义 token 一一对应**，切换主题不改变任何布局与信息层级。
- 允许为某主题做**微调**（例如浅色下极光透明度更低），但**不允许**只在深色下成立的设计。
- 不使用 Material You / dynamic color：系统壁纸色会覆盖极光品牌色。

### 2.1 桌面皮肤系统（Desktop Skins）

桌面在「明暗」之上再叠一层**皮肤（skin）**：每套皮肤是一整套内置外观，用户可在
「设置 → 外观」切换。**默认皮肤是「品牌」**——品牌青绿主按钮 + 中性灰面 + 发丝边；
其他皮肤可以换整套配色、并附带一个可选氛围特效，但**结构、间距、圆角、组件解剖不变**。
原型见 `docs/ui/desktop/preview.html`（默认品牌）。

三个轴，互不混淆：

| 轴 | 管什么 | 落地 |
|---|---|---|
| `theme` | 明暗（浅 / 深 / 跟随系统） | `data-theme` |
| `skin` | **整套内置外观**：配色 + 可选氛围特效 | `data-skin` |
| `fx` | 特效层（背景动画 / 鼠标波纹），可选、默认关 | `data-fx` + `SkinFx` |

- 每套皮肤**必须同时提供浅色与深色**；切换明暗不改变布局。
- 皮肤只改**颜色 / 材质 token**；字号、间距、圆角、图标、动效时长、组件结构不随皮肤变。
- 每套皮肤 × 每套明暗都必须过 §3.4 / §10 的对比度与可读性底线。
- 特效是皮肤的**可选属性**，默认 `none`；关闭特效时皮肤必须完整好看。
- 新增皮肤 = `tokens.css` 写 `[data-skin='<id>']` 一组变量 + `skins.ts` 注册一行
  （详见 `desktop/docs/skins.md`）。

- **品牌色统一交互**：主按钮、可交互图标、焦点环、选中文字都用 `primary`；主按钮填充用
  `primary-fill` + 深墨字 `on-primary-fill`。**不用白字压亮青**。
- **彩色守恒**：品牌色与状态色的同屏面积 ≤10%，其余是中性色；一屏只有一个视觉焦点。
- **选中用灰胶囊**：`surface-2` + `text-primary`，**不加彩色左条**；运行中的会话只加脉冲圆点，不再加竖条。
- **发丝边**：分隔与描边用 0.5px（`inset 0 0 0 .5px var(--hairline)`），不是 1px 灰线。
- **圆角**：卡 16 / 模态·Sheet 20 / 控件与按钮 10。
- **阴影**：极轻；卡片基本无影（靠灰面 + 发丝线分层），模态用大而淡的阴影。
- **默认不启用玻璃 / bloom**；皮肤特效（`SkinFx`）**保留为可选的第二轴**，默认 `none`，
  开启后只做氛围层、不改基础配色与可读性。连接页最多一层极淡中性光。
- **皮肤特效**沿用现有 `[data-fx]` 机制（`--page-bg` 透明、面板让位）；配色从 `accent` + 中性色取，
  不用移动端极光色。
- **按钮**：高 34、文字 12.5–14；主按钮品牌填充 + 深墨字，次按钮白面 + 发丝边。
- **字体**：UI 用系统栈（`-apple-system` / `Segoe UI` / `PingFang SC` / `Microsoft YaHei`），数据用等宽。

#### 2.1.2 首批内置皮肤

**已定**：

- `brand`（**品牌**，默认）：中性灰面 + 发丝边 + 品牌青绿主色，浅 / 深各一组 token。
- `ripple`（**涟漪**，可选）：品牌配色 + 鼠标涟漪特效；特效默认关，关闭时等同于品牌外观。

**待定**：其余内置皮肤的数量、命名、气质与配色。新增时按 §2.1.3 契约补齐浅 + 深 token
与验收截图，再进设置页的皮肤列表。

#### 2.1.3 新增皮肤契约

- **完整 token**：每套皮肤必须覆盖浅/深两套的 `bg / surface / card / surface-2 / surface-3 /
  text-* / primary-fill / on-primary-fill / accent / success / warning / error / code-bg / hairline`。
  未覆盖的 token 回落到默认皮肤「品牌」。
- **主按钮可换色**：`primary-fill` 与 `on-primary-fill` 对比度 ≥4.5:1（大字 ≥3:1）；
  高饱和面积仍 ≤10%。默认品牌用青绿填充 + 深墨字；其他皮肤同理，必须配深/浅墨字，不用白字压亮色。
- **结构不可覆盖**：字号、间距、圆角、阴影层级、动效时长、图标、组件解剖不随皮肤变。
- **特效只在 `fx`**：不把玻璃 / bloom 写进内容层；特效默认关，开启时只做背景氛围。
- **验收**：每套皮肤至少一张浅色 + 一张深色截图，过 §10 与 §12.2。
- **注册**：`desktop/src/renderer/src/ui/skins.ts` 的 `SKINS` 加一行；配色写在
  `tokens.css` 的 `[data-skin='<id>']`（浅/深各一组）。

### 3.2 极光光源

极光是**光**，不是漆。三档色标，按用途取用：

| 名称 | 深空 | 晨光 | 用途 |
|---|---|---|---|
| `aurora-teal` | `#45E0C2` | `#7FE0C8` | 主光（与 primary 同源） |
| `aurora-blue` | `#5FA8FF` | `#8FB8FF` | 中段 / 进行中 |
| `aurora-violet` | `#9C8CFF` | `#B6A8FF` | 远端 / 思考 / 神秘感 |

- **极光细线**：`linear-gradient(135deg, aurora-teal, aurora-blue 50%, aurora-violet)`，用于
  焦点边、hero 分割线、进度条。粗细 ≤2px。
- **极光光晕（bloom）**：`radial-gradient(closest-side, 主光, transparent 70%)`，深色透明度
  `0.12–0.18`，浅色 `0.08–0.12`，模糊 60–120px。一屏一个（§1）。

### 3.3 状态色语义（全局一致）

| 状态 | 用色 | 形状/图标（不只靠色） |
|---|---|---|
| 运行中 | `info`（极光蓝） | 旋转环 / 脉冲点 |
| 成功完成 | `success` | ✓ |
| 警告 / 待注意 | `warning` | ! / 三角 |
| 失败 / 危险 / 拒绝 | `error` | ✕ / 盾 |
| 思考中 | `thinking` | 微光文字 + 三点 |
| 已完成但「人类时刻」 | `accent-warm` | 暖光勾 |

- **一个颜色只表达一件事**：`primary` 只表示「品牌/可交互/选中」，不兼职状态。
- 状态**永远**色 + 形 + 字三重表达，满足色觉障碍。

### 3.4 对比度核算（WCAG 2.1 相对亮度）

正文目标 **≥4.5:1**，大字（≥18pt 或粗体 ≥14pt）**≥3:1**。

| 组合 | 比值 | 结论 |
|---|---|---|
| 深：`text-primary` / `bg` | ≈17.1:1 | ✅ |
| 深：`text-secondary` / `bg` | ≈8.9:1 | ✅ |
| 深：`text-muted` / `bg` | ≈4.8:1 | ✅ |
| 深：`primary` / `bg` | ≈12.0:1 | ✅ |
| 深：`on-primary-fill` / `primary-fill` | ≈10.0:1 | ✅ |
| 深：`success` / `bg` | ≈11.1:1 | ✅ |
| 深：`accent-warm` / `bg` | ≈11.2:1 | ✅ |
| 浅：`text-primary` / `surface` | ≈18.0:1 | ✅ |
| 浅：`text-secondary` / `surface` | ≈6.5:1 | ✅ |
| 浅：`text-muted` / `surface` | ≈4.8:1 | ✅ |
| 浅：`primary` / `surface` | ≈5.1:1 | ✅ |
| 浅：`on-primary-fill` / `primary-fill` | ≈7.4:1 | ✅ |
| 浅：`success` / `surface` | ≈5.4:1 | ✅ |
| 浅：`error` / `surface` | ≈5.3:1 | ✅ |

> 表中未列的组合在实现前必须实测；任何「浅色用主色当小字」「深色用 muted 当正文」都要重新核算。
> 新增颜色先算对比度，再进 token。

### 3.5 使用规则

- **禁止纯黑纯白铺面**：白只给 `surface`（浅色），黑只给最底 `bg`（深色），内容面永远抬一档。
- **禁止硬编码状态色**：一律走语义 token。
- **暖色克制**：暖光是「人味」的调味，不是第二主色；同屏暖色面积小于主色。
- **选中不用整块实色**：深色用 `primary-subtle` + 2px 左光条；浅色同理，避免像按钮。

## 4. 字体系统

系统字体（iOS SF / Android Roboto / 桌面系统栈），**不引入第三方展示字体**：CJK 一致性优先，
个性靠字重、字号、字距与等宽数据的对比来建立。

### 4.1 语义字号

| 语义角色 | 移动（sp/pt） | 桌面（px） | 字重 | 行高 | 用途 |
|---|---|---|---|---|---|
| `display` | 28–32 | 22 | 600 | 1.2 | 连接页 hero、空态大标题 |
| `title-1` | 22 | 22 | 600 | 1.3 | 页面标题（桌面设置/页面主标题） |
| `title-2` | 16 | 15 | 600 | 1.4 | 卡片 / 区块标题 |
| `body` | 15 | 14 | 400 | 1.5 | 正文 |
| `body-sm` | 13 | 13 | 400 | 1.5 | 辅助正文 |
| `caption` | 11 | 11 | 500 | 1.4 | 角标 / 说明（下限，勿再小） |
| `mono-body` | 13 | 13 | 400 | 1.5 | 代码 / 路径 / 命令 / 工具输出 |
| `label-meta` | 11 | 11 | 600 | 1.2 | 等宽大写小标签（eyebrow） |

- 移动端正文从旧的 14 提到 **15**，长时间阅读更舒服；桌面保持 14 保密度。
- 不用 Light / Thin 做小字；`display` 也不用 Hairline。
- **中文字距**为 0；`label-meta` 的大写 + `letter-spacing: .06em` **只对拉丁字符**生效，
  中文标签不加字距、不强制大写。
- 等宽字体：移动 JetBrains Mono / SF Mono，桌面 JetBrains Mono / Cascadia，兜底系统 mono。

### 4.2 排版性格

- **层级靠字重与大小，不靠颜色**：标题 600 + 更大，正文 400，弱化才用 `text-secondary`。
- **数据用等宽**：时间、token 数、模型名、路径、命令、工具名——等宽让它们「像仪表读数」，
  天然带出科幻感。
- **小标签像仪器铭牌**：区块 eyebrow 用 `label-meta`（等宽、静音色），给结构编码，不装饰。
- 标题不求大，求「稳」：`title-1` 22pt 已足够，靠留白撑气场。

## 5. 空间、圆角与网格

### 5.1 间距（4pt 网格）

| Token | 值 | 用途 |
|---|---|---|
| `space-1` | 4 | 图标与文字、紧邻元素 |
| `space-2` | 8 | 行内分组 |
| `space-3` | 12 | 卡片内元素 |
| `space-4` | 16 | 卡片内边距（桌面常用） |
| `space-5` | 20 | 页面左右留白（移动）、卡片内边距 |
| `space-6` | 24 | 区块间距（移动） |
| `space-8` | 32 | 大区块 / 章节 |
| `space-10` | 40 | hero / 空态 |

- 移动：页面左右 **20**，区块间距 **24+**，列表行高 ≥56。
- 桌面：页面 **24**，区块 **16–20**，列表行高 ≥44（密度优先）。

### 5.2 圆角

| Token | 移动 | 桌面 | 用途 |
|---|---|---|---|
| `r-sm` | 8 | 8 | 角标 / 小控件 |
| `r-md` | 12 | 10 | 控件 / 按钮 / 分段 / 输入内层 |
| `r-lg` | 16 | 16 | 卡片 / 面板 / 输入框 |
| `r-xl` | 20 | 20 | 大卡 / 模态 |

### 5.3 布局

- 用**可用宽度**而非设备类型决策布局（延续现有原则）；桌面三栏（左栏 300 / 主区 / 可选右栏 420）。
- 聊天正文移动满宽减 20 gutter；桌面内容列最大 **720 居中**，代码区不限宽可横滚。

## 6. 层次与材质（克制版）

### 6.1 三层景深

```
canvas（画布：bg / canvas）  ← 最底
  └─ panel（面板：surface）  ← 卡片、栏面、列表
       └─ floating（浮层：glass / surface-3 + 光晕）← Tab 栏、顶栏、输入、Sheet、弹窗
```

- 每升一层，**亮度+一档 / 阴影+一档 / 描边-一档**，不要一层同时加大阴影又加粗边框。
- **深色靠「光」分层**（亮度台阶 + 顶部内高光 + 微光晕），阴影几乎不可见；
  **浅色靠「影」分层**（柔和低透明阴影 + 极淡描边）。

### 6.2 玻璃（只在浮层）

| 属性 | 深空 | 晨光 |
|---|---|---|
| 背景 | `glass` | `glass` |
| 模糊 | `blur(20px)` | `blur(18px)` |
| 描边 | 1px `glass-border` | 1px `glass-border` |
| 顶部高光 | `inset 0 1px 0 glass-highlight` | `inset 0 1px 0 glass-highlight` |

规则：

- **只用于漂浮功能层**，内容卡片不用。
- **不叠玻璃**：玻璃面内不再放玻璃元素。
- **必须有降级**：`Reduce Transparency` / 不支持 blur（旧 Android）时，换成不透明 `surface` +
  `border`，布局不变。
- 玻璃上文字必须满足对比度；玻璃下的内容避免高细节（否则「脏」）。

### 6.3 极光光晕（bloom）

- 形态：单色或双色的 `radial-gradient(closest-side, …, transparent 70%)`，模糊 60–120px。
- 位置：**焦点后方**，不压正文；可略溢出焦点边缘形成「呼吸」。
- 数量：**一屏最多一个**。运行中的会话、主 CTA、连接页 hero 三选一。
- 透明度：深 `0.12–0.18`，浅 `0.08–0.12`；`Increase Contrast` 下降到 ≤`0.06` 或关闭。
- 禁止：当成背景铺满、多个光晕抢焦点、给每个卡片都加光。

### 6.4 阴影

| Token | 深空 | 晨光 |
|---|---|---|
| `e-1`（卡片） | `inset 0 1px 0 rgba(255,255,255,.04), 0 1px 2px rgba(0,0,0,.40)` | `0 1px 2px rgba(15,23,34,.06)` |
| `e-2`（浮层/Sheet） | `0 8px 24px rgba(0,0,0,.45)` | `0 8px 24px rgba(15,23,34,.08)` |
| `e-3`（全屏浮层/审批） | `0 16px 48px rgba(0,0,0,.60)` | `0 16px 48px rgba(15,23,34,.14)` |

- 深色阴影是「托底」，不是主层次手段；浅色阴影要**大而淡**，不要小黑块。
- 描边只 1px；**2px 只允许**给焦点环与审批卡（安全边界）。

### 6.5 边框与分隔

- 默认 1px：深色 `border`、浅色 `border`；只在需要时出现。
- 列表分隔优先用**间距 + 极淡线**，不要做「表格网格」。
- 输入框常态用 `border-strong`，聚焦用 `primary` 1.5px + 外发光（`0 0 0 3px primary-subtle`）。
  **桌面输入类控件聚焦不加描边**：只保留光标与淡染选中底；键盘焦点环只给按钮 / 链接（35% 品牌色）。

## 7. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 微交互（hover / 按压 / 勾选） | 120ms | `cubic-bezier(.2,0,0,1)` |
| 标准（展开 / 切换 / 淡入） | 200ms | `cubic-bezier(.2,0,0,1)` |
| 浮层（Sheet / 模态进出） | 280–320ms | 进入减速、退出加速；Sheet 轻微弹簧 |

- **运行脉冲**：2.4s `ease-in-out`，透明度 `0.4 ↔ 0.75`，只用在运行指示。
- **思考微光**：1.8s 扫过，只用在「思考中」一行。
- **只动该动的**：列表滚动、流式增字不刻意加动画；新元素淡入 + 轻微上移 ≤8px 即可。
- **降级**：`Reduce Motion` 下所有持续动效停为静态（脉冲变常亮、微光变纯色），交互动画改为瞬时。
- **一次一个**：同屏最多一个持续动效；多条运行用「共享节奏」或只动最新一条。

## 8. 图标与插画

- **线宽 / 网格**：24 网格、1.75 描边、`currentColor`；移动展示 22–24，桌面 15–16。
- **库映射**：Android Material Symbols（Rounded）、iOS SF Symbols、桌面本地 stroke set。
- **选中态**：Tab 图标可用填充变体 + `primary`，但**永远配文字**。
- **状态用语义图标**：✓ / ✕ / ! / 旋转 / 盾，一以贯之；**不用 emoji、不用字符字形**。
- **插画**：只在空态与连接 hero 出现，风格「极光 + 微光几何」，低细节、低饱和；
  空态插画不抢主行动按钮。

## 9. 组件外观规范

> 原则：**语义与交互不变，只换皮相**。以下每条都是对现有 M3 / UIKit 默认外观的替换要求；
> 尺寸数值见 §4/§5，颜色见 §3。

### 9.1 底部 Tab（移动）/ 活动栏（桌面）

- **移动**：悬浮胶囊玻璃条（左右各 20、距底 8、圆角 28、高 ≈56）；icon 20 + 文字 11；
  选中 `primary` + 文字；**无顶部整条分隔线**；不用 Material `NavigationBar` 默认 80dp。
- 选中可加**极小的光点/辉光**而非整块色；未选中 `text-muted`。
- **桌面**：最左 48px 常驻活动栏，上「会话 / 定时任务」、左下「设置」；选中 = `surface-2`
  灰胶囊（**不加彩色条**）。切到任务 / 设置时隐藏会话栏，页面占满活动栏右侧；
  只有「运行中」的会话加脉冲圆点（不加竖条）。

### 9.2 顶部栏

- 透明起步，内容滚动到下方后渐变为**玻璃**（blur + `glass-border` 下边）。
- 标题 `title-1` 600；返回键为 32 圆形中性玻璃钮；右侧动作为**32 圆形中性玻璃钮**（icon 18，
  `primary`），不用裸 `IconButton`、不用大描边圆钮。
- 不做「顶部整条绿色/实色」；顶栏不额外叠状态栏高度。

### 9.3 会话卡片

- **降高度、提密度**：标题 `title-2` 最多 2 行；元信息行（runtime 徽章 + 相对时间）用等宽小字。
- 卡面：`surface` + `r-lg`；深色加 `e-1` 光边，浅色加 `e-1` 柔影；**不用粗描边**。
- **运行中**：卡片左侧 2px 极光条 + 右上脉冲点 + 背后一处淡 bloom（此屏唯一的 bloom）。
- **选中**：`surface-2` 或 `primary-subtle` 淡染 + 2px 左光条；不整块实色。
- 会话列表不再「每张卡又大又空」：卡片间距 12，内边距 16，标题与徽章紧贴。

### 9.4 聊天气泡与 Markdown

- **助手回复不再套大白卡**：正文直接落在 `canvas` 上，满宽减 gutter，靠排版与留白分层。
  连续的工具/思考块之间用间距分组，不再用卡片切割文字。
- **用户消息**：右对齐气泡，`primary-subtle` 底（浅色）或 `#10302B` 淡染（深色），`r-lg`，
  文字 `text-primary`，下方时间 `caption`。
- Markdown：`body` 15/14；代码块 `code-bg` + `r-md` + 1px `border`，等宽 13；引用用 2px 左光条
  而非整块底色；表格线极淡。
- 流式光标用 `primary` 细竖线，不闪烁抢眼。

### 9.5 工具组 / 工具卡 / 思考

- **工具组折叠行**：单行等宽摘要 `N 个工具 · Write, Bash, Read…` + 状态摘要；无卡面、无重边框，
  只有极淡上下分隔；展开后逐个工具卡。
- **工具卡**：`code-bg` + `r-md` + 1px `border`；头部图标 + 工具名（等宽）+ 状态点；展开区等宽、
  可复制、可横滚。
- **思考**：一行 `thinking` 色微光文字 + 三点；**不画卡**（移动端若需卡，仅用极淡底，无描边）。
- **状态**：运行=极光蓝旋转；完成=success ✓；失败=error ✕；中断=warning —（不是失败）。

### 9.6 输入区（Composer）

- 玻璃胶囊（`glass` + blur）或 `surface-2` 圆角 20；**不要 2px 实色青边**。
- 聚焦：1.5px `primary` + `0 0 0 3px primary-subtle` 外环 + 一处极淡 bloom。
  **桌面不加任何聚焦描边**（见 §6.5）：输入卡是白面 + 柔和投影，聚焦只把投影加深一档。
- 发送：圆形 `primary-fill` + `on-primary-fill` 图标；禁用用 `surface-3` + `text-disabled`。
  **桌面**改为品牌淡染 pill（同 `.btn.soft`，13% 品牌色 + 20% 描边），不抢正文。
- 工具入口（语音等）为 32–36 中性玻璃圆钮，与发送键左右呼应，不抢主按钮。

### 9.7 按钮 / 分段 / 单选 / 开关

- **主按钮**：`primary-fill` 填充 + `on-primary-fill` 文字 + `r-md`/`r-pill`；
  可加**极淡内高光 + 轻辉光**（克制，不是霓虹）。禁止整块大面积亮色铺满页面。
- **次按钮**：玻璃/描边，`text-primary`；**文字按钮**：`primary`。
- **危险按钮**：`error` 描边 + `error` 文字；确认才用 `error` 填充 + 白字。
- **分段控件**：玻璃轨道 + 滑动胶囊（选中 `surface`/`primary-subtle` + 轻微影），
  不用 M3 默认描边分段。
- **单选**：20 环 + 10 实心点，选中 `primary`；**开关**：36×22 胶囊，开 `primary-fill`，旋钮带柔影。
- **触控**：移动 ≥44；桌面 ≥28（图标钮 ≥24）。

### 9.8 设置

- 分区块，区块标题用 `label-meta`（等宽静音）+ 上方间距 32；行高移动 ≥56、桌面 ≥44。
- 行内控件右对齐、克制尺寸；**不要一行一个巨大收音机**。
- 说明文字 `body-sm` `text-secondary`，紧贴标题下方；危险项单独成块并 `error` 标注。

### 9.9 Sheet / 模态 / 审批

- Sheet：顶部圆角 28，玻璃或 `surface`，grabber 36×4 `text-muted`；遮罩 `scrim` + 轻度 blur。
- 模态（桌面）：`surface` + `r-xl` + `e-3`；无底部 Sheet 概念。
- **权限审批（安全边界，不可妥协）**：
  - 视觉最重：`error`/`warning` 1.5px 边 + `e-3` 阴影 + 顶部一抹暖/红 bloom。
  - 命令/参数用 `code-bg` 等宽块；作用域（会话 + 工具）用 `label-meta` 明示。
  - 按钮：**拒绝**（描边 error）、**允许一次**（primary-fill）、**允许全部**（需二次确认）。
  - 不用低饱和「温柔」处理——它是唯一允许抢眼的地方。

### 9.10 徽章 / 状态胶囊 / 空态

- **Runtime 徽章**：身份色圆点 + 名称 + 同色淡染胶囊（`r-pill`，11–12）；未知 id 中性兜底。
- **状态胶囊**：色 + 图标 + 文字三件套；进行中有脉冲，静止态不呼吸。
- **空态**：一处淡 bloom + 一句说明 + 一个主行动；不用大插画填满，留白即治愈。

### 9.11 连接页 Hero（签名时刻）

- **移动**：全站唯一允许大面积渐变的地方——顶部一处极光 bloom（青→蓝→紫）+ 品牌标/吉祥物 +
  `display` 大标题 + 一句定位语。表单卡：玻璃 / 白面 + `r-xl` + `e-2`，输入框 `border-strong` 常态、
  聚焦 primary 环。
- **桌面**：不铺极光；居中白卡（`r-xl` + 大而淡的阴影）+ 品牌标（青色渐变）+
  品牌青绿主按钮（深墨字），背景最多一层极淡中性光。同样安静、可信，但更克制。

## 10. 无障碍底线（一票否决）

- **对比度**：正文 ≥4.5:1，大字 ≥3:1；每次改色实测（§3.4）。
- **字号**：移动最小 11pt、桌面最小 10px；动态字号放大到 200% 布局不塌、层级不丢。
- **触控**：移动 ≥44×44，桌面 ≥28×28（图标 ≥24）；控件间距足够防误触。
- **不靠颜色**：状态、错误、选中都配图标/形状/文字。
- **动效**：`Reduce Motion` 全量降级；无「只能靠动画理解」的信息。
- **透明**：`Reduce Transparency` 玻璃降级为不透明面；`Increase Contrast` 描边变实、文字更深、光晕减弱。
- **键盘（桌面）**：所有交互可达，焦点环可见（`primary` 1.5px + 3px 淡环），顺序合理。
- **读屏**：图标钮必有语义标签；工具/审批的关键字段可朗读。

## 11. 三端落地映射（token → 实现）

> 只记落点，不重复数值。数值以本文件 §2.1–§7 为准（移动端 §3–§7，桌面 §2.1）。

### Android（Jetpack Compose + Material 3）

| 关注点 | 落点 |

## 12. 迁移步骤与验收

### 12.1 顺序（先底座后页面，避免返工）

1. **Token 层**：移动端换 v2 极光；桌面先落默认皮肤「品牌」，再按 §2.1 接皮肤切换
   （每套皮肤浅/深各一组 token，未覆盖回落品牌）。
2. **基础组件**：按钮、输入、单选、开关、分段、Tab/左栏、顶栏、卡片、Sheet、状态徽章。
3. **核心页面**：会话列表 → 聊天（气泡/Markdown/工具组/工具卡/思考）→ 输入区 → 审批浮层。
4. **次级页面**：设置、工作区、新建会话、任务、文件、目录选择。
5. **收尾**：连接 hero、空态、动效、两套主题精修、无障碍降级。

> 建议每端按此顺序独立提交；三端共享语义但各自落地，**不追求像素级一致**。

### 12.2 验收清单（每端每页过一遍）

## 附录 B · 禁止清单（反模式）

- ❌ 纯黑背景 + 纯白卡片的高反差「黑客风」；❌ 整页/整卡铺极光渐变。
- ❌ 每张卡都发光、每个图标都彩色；一屏多个视觉焦点。
- ❌ 用 M3 默认 `NavigationBar / RadioButton / Switch / SegmentedButton / TopAppBar` 的原样外观。
- ❌ 2px+ 实色描边（焦点环与审批卡除外）；粗边框 + 重阴影叠用。
- ❌ 白字压亮青填充、浅底用主色当小字（对比度不足）。
- ❌ 玻璃叠玻璃；玻璃里放高细节内容；无降级的毛玻璃。
- ❌ 状态只用颜色；只用 emoji/字符做图标；正文用等宽。
- ❌ 大面积暖色或第二主色；把「治愈」做成「可爱/糖果化」。
- ❌ 持续动画超过一个；动效抢于内容。
- ❌ 品牌主按钮用白字压亮青，或把品牌色铺满卡片 / 整块选中态——主按钮配深墨字，选中用灰胶囊。
- ❌ 一套皮肤只做浅色或只做深色；每套皮肤必须两套齐全。
- ❌ 皮肤改字号 / 间距 / 圆角 / 组件结构；皮肤只覆盖颜色 / 材质 token。
- ❌ 桌面让基础外观依赖玻璃 / 极光 bloom / 特效才成立；特效应可选、默认关，且不改基础配色。
- ❌ 桌面用 1px 灰线堆「表格感」；用 0.5px 发丝线 + 留白分层。
