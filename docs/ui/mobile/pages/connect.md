### 6.1 ① 连接服务器页（Connection）🟢

**目的**：填写电脑上 daemon 的地址与 token，建立连接。

**关键元素**（自上而下，Android 与 iOS 一致）：
1. 产品 Logo + 名称 + 一句 slogan（"一个客户端，操纵你所有的 agent"）。
2. 服务器地址输入框：`192.168.1.2:4780`（等宽字体、带 `http://` 前缀提示；缺 scheme 时自动补 `http://`）。
3. Token 输入框：**64 位 hex**，**支持密码隐藏 + 一键显示**（右侧小眼睛图标切换，不用文字按钮）+ 粘贴。
4. 名称输入框（可选）：给这台电脑起可读名字，连接后各处用它代替地址。
5. 主按钮「连接」（primary，全宽）。
6. 「最近连接」列表（若有历史，卡片列表）：每项显示**名称（未命名时为掩码地址）+ 掩码地址**，不显示明文 token。
   - 只记录**连接成功过**的地址+token，最新在前，最多 5 条；**同一地址只留最新一条**（token 轮换后自动覆盖）。
   - 点击**只回填表单**（地址/token/名称），不自动连接，方便先改再连。
   - **左滑**该条才露出「编辑 / 删除」；编辑弹窗可改**名称、地址、token**（地址与 token 必填），
     保存后原地更新该条。动作按钮不常驻（同一时刻只允许一条滑开）。
   - 当前输入框里的地址不一定在列表里（未连接成功过的不记录）。
7. 底部小字安全提示："token 等同于在电脑上执行命令的权限，请只在可信网络或隧道中使用。"

**地址展示规则**：连接成功后一律优先显示名称；确需显示地址时只显示掩码（IPv4 只保留第一段、
端口也一并遮住，如 `192.*.*.*:****`；IPv6 保留首段并遮住端口），不在界面上直接暴露完整 IP 与端口。

**交互**：
- 点「连接」→ 显示 loading（按钮转圈）→ 校验通过进入会话列表；失败显示错误文案 + 保持输入。
- **冷启动跳过本页（Android / iOS 一致）**：本机已保存过成功连接（地址 + token）时，冷启动直接以**会话列表**为起点，本页不再闪现。连接失效不在这里拦——由会话列表的错误态 + 「重试」兜底，改地址 / token 走设置页的「重新连接」再进本页（或左滑最近连接编辑）。只有本机没有保存连接时才停在连接页。
- 支持**扫码连接**（若后端提供二维码，见附录 B）：右上角扫码 icon，扫描后自动填好地址+token。

**状态**：
- 校验中：按钮 loading。
- 失败：输入框下方红字错误（区分"无法连接" / "token 无效"）。
- 成功：自动跳转会话列表，token 本地持久化。
