# ⑬ 关于你（Memory）— 移动端

> 索引见 [../README.md](../../README.md)；Design Tokens 见
> [../../shared/design-principles.md](../../shared/design-principles.md)。
> M1 只读 + 改正 / 忘记；workspace 记忆开关与画像只读展示，配置只在桌面。

## 入口

- 「生活」工作区概览 →「关于你」信息卡 → 独立页面（push）。
- 会话列表与「关于你」同级：返回回到概览。

## 页面结构

1. **顶栏**：标题「关于你」+ 返回。
2. **状态条**：
   - 有模型：`自动整理（provider:model）· N 条待整理`；
   - 无模型：`仅记录，未整理` + 到桌面设置勾选的提示。
   - 已配置但不可用：`记忆模型配置不可用` + 检查 Key/启用状态/模型目录的提示。
   - 第二行只读展示 workspace 开关：`记忆已启用/未启用 · 注入/只记录 · 画像 x · 生活可读/不可读`；
     修改入口提示「请在桌面端修改」。
3. **最近工作（只读）**：有 observation / summary 时在记忆列表前显示最近 6 条，
   带「摘要 / 观察」、日期、文件数；无数据不显示。
4. **重复候选（只读）**：Tier-1 待审候选，显示两侧摘要与相似度；合并 / 忽略请在桌面端处理。
5. **搜索框**：匹配摘要、内容、predicate、来源原话。
6. **分组列表**：`关于你(fact)` / `偏好(preference)` / `关系(relation)` / `画像(profile)`。
   - 组头：展开箭头 + 名称 + 数量；默认展开，可折叠；空分组不显示。
   - **紧凑行**：摘要最多 2 行 + 权威标记（你已确认 / 自动整理）+ 私密标记 + `#xxxx`。
   - 排序：`user_confirmed` 优先，其次 importance，再按 updatedAt 倒序。
   - 无记忆 / 无匹配均有明确空态。
7. **详情**：
   - Android：`ModalBottomSheet`；
   - iOS：push 到「记忆详情」页。
   - 内容：类型 / 权威 / 私密 / 短 ID、摘要、内容、置信度 / 更新 / 有效期、来源原话、
     `改正` / `忘记`。
8. **改正**：弹窗输入摘要 + 内容；保存后标记 `user_confirmed`，刷新列表。
9. **忘记**：二次确认；删除后返回列表。

## 边界

- 不提供新建记忆、模型选择、批量操作。
- `private` 可展示并带标记；`secret` 服务端不会返回 / 注入。
- 列表首次进入显示 loading；刷新时保留旧列表，避免闪屏。
