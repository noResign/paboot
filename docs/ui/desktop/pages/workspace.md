# ⑫ 工作区概览 / 目录（Workspace）— 桌面

> 索引与全局规范见 [../design.md](../design.md)。移动端无独立页：工作区概览收在会话页
> 工作区 sheet 里；本文件只写桌面差异。
>
> **不引入「项目」层**：工作区就是顶层容器，`workspace.path` 是主目录，`dirs` 是附加目录。

### 6.2a ⑫ 工作区概览 / 目录 → **主区**

**目的**：一眼看清这个工作区由哪些目录组成、最近在做什么，并完成目录级操作。
它是「点工作区名」后的二级页；没有选中会话时，主区也默认落在这里。

**入口**：
- 左栏顶部工作区名 / `▾` → 「工作区概览」；
- 无会话时的主区默认；
- `⌘K` → 「工作区：概览」。

**关键元素**：

1. **页头**
   - 工作区名（可重命名，走 ⑧ 工作区管理）；
   - 主目录路径（等宽、单行省略，可复制）；
   - 主操作：`[+ 新建会话]`、`[+ 添加目录]`、`[工作区设置]`。
2. **目录区**（本页核心）
   - **主目录行**：徽章「主目录」+ 路径 + 会话数 + 最近使用时间。
     - 主目录不可移除；v1 不支持「改主目录」。
     - 右侧操作：复制路径、在此新建会话。
   - **附加目录行**：路径 + 会话数 + 最近使用时间；右侧 `⋯`：
     - 复制路径；
     - 移除附加目录（不删磁盘；有会话 cwd 在此则禁用并说明）。
   - **添加目录**：打开 ⑨ 目录选择器（文案「添加附加目录」/「添加此文件夹」），
     写入 `workspace_dirs`；同一路径去重；已是工作区也允许（同一目录可被多个工作区引用）。
   - **说明**：附加目录会扩大**该工作区所有会话**的可写范围；不是「只给当前对话」。
   - **空态**：只有主目录时，显示一行「未添加附加目录」+「添加目录」入口，不占大块空白。
3. **最近会话**
   - 最近 5–8 条；行内显示 `标题 · agent · 目录名 · 相对时间`。
4. **知识（K0）**
   - 入口：概览页「知识」区 → 知识面板（overlay）。
   - 列表：标题 / 类型 / 端（仅已有端级文档）/ 核验状态 / 更新时间 / 摘要；按
     「全部 / 未核验 / 已核验 / 缺失」筛选，支持标题 / 摘要 / 标签 / 正文搜索。
   - **新建**：点「新建」弹出类型选择——**规范文档 / 知识 / 需求 / 自定义**。
     规范文档全工作区只允许一份，已存在时直接打开现有文档；知识与需求落到
     `knowledge/` / `requirements/`（目录不存在自动创建）；自定义不预设类型和标题，
     由用户完整填写。新建/编辑表单当前只包含标题、类型（自定义时可选）、摘要、正文；
     **端和标签字段已移除**。
   - 详情：markdown 源码编辑、保存、标记已核验 / 取消核验、删除、导出 ZIP。
   - **收录策略**：知识目录里的文件自动收录，按指针注入（Claude/Codex 每轮、
     DeepSeek 新会话首条、builtin 每步），不要求人工确认；新建工作区自带一份已核验的
     `WORKSPACE.md`。`未核验` 只是提示标记，注入指针里带「（未核验）」。人工编辑 / 保存会
     自动标记为已核验；外部修改会重置为未核验。
   - 知识根作为 dev run 的附加目录暴露给 runtime，agent 可以直接 Read/Write；
     DeepSeek 因 ACP 限制走提权审批。
   - 删除是**永久删除**（不可恢复）；需要保留先导出 ZIP。
5. **端**
   - 工作区概览**直接平铺端**（不再有「端 / 能力」卡片）：每端显示名称 / kind / 目录数 /
     summary / 已启用能力；「添加端」= 选领域 → 命名 → 挂目录 → 勾选能力。
   - 点端进入详情：目录、能力开关、领域规范 / 知识、描述与注意事项、归档 / 恢复 / 移除。
   - 能力是全局目录，在**设置 → 能力**查看；端只勾选启用哪些。Mock 也可作为端能力选择。
   - 设备类能力（当前 android-device）从端详情的「打开设备面板」进入；面板固定该端，无全局端选择器。
   - 端详情里可「添加目录 / 移除目录」；端目录需位于主工作区或已添加的附加目录内。
   - active 端先「归档」才能「移除」；两者都会先展示影响预览。设备面板只在设备能力启用时出现。
   - **不出现「项目」**；端不占导航层级。

6. **新建会话默认值**
   - 工作区管理卡提供「默认 Agent」「默认权限」两个下拉；`跟随全局` = 清除为 `null`。
   - 新会话模态按这里的值预选；已有会话不受影响。
7. **危险区入口**
   - 「工作区设置」→ 6.9（重命名 / 删除 / 导入导出）；本页不直接放删除按钮。

**交互**：

- 「在此新建会话」→ 6.4 新建会话模态；工作区固定，位置默认该目录；
  v1 只有主目录可作为 cwd，附加目录的「在此新建会话」暂不出现（M2/M3 再开）。
- 添加 / 移除目录 → `POST/DELETE /api/workspaces/:id/dirs`；成功后刷新本页与左栏会话计数。
- 移除附加目录有会话 cwd 在此 → 禁用按钮 + tooltip「该目录仍有会话，先迁移或删除会话」。
- 目录路径点击 → 复制；hover 显示复制图标。
- 工作区切换 → 本页整体替换，不保留上一个工作区的滚动位置。
- 知识面板：打开时拉 `GET /api/workspaces/:id/knowledge`；保存 / 核验 / 删除后刷新列表；
  导出走 `GET .../knowledge/export`，由 main 进程弹原生保存框（ZIP 字节不进 renderer）。

**状态**：

- **只有 fallback**：显示「还没有添加工作区」空态 + 「添加工作区」；
  fallback 不出现在切换器 / 本页。
- 加载中：页头 + 3 行目录骨架。
- 无附加目录：主目录行 + 一行轻量「添加目录」。
- 目录不存在 / 无权限：该行标红 + 「重新选择 / 移除」；相关会话不可跑。
- 工作区被删 / 无权限：回退到默认工作区；不要白屏。
- 添加目录失败：`dir_exists` 就地提示并定位已有行；`directory_not_accessible` 提示权限 / 路径。
- 知识：无文档时显示「放文件到知识目录会自动收录」；未核验条目用 warning 色标记；
  文件缺失标红并提示可删除 / 清理。

**与移动端的差异**：

- 移动端不做工作区创建 / 目录增删；只在工作区 sheet 里只读展示主目录 + 附加目录。
- 桌面用主区整页，信息密度更高；目录行可直接操作，不放进设置页的二级列表。
- 移动端「工作区管理」仍保留在设置里；桌面把「概览」和「管理」分开：
  概览看目录 / 最近会话，管理做重命名 / 删除 / 导入导出。
