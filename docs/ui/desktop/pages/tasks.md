# ⑪ 定时任务（桌面端）

> 索引见 [../design.md](../design.md)；共享语义见
> [../../mobile/pages/tasks.md](../../mobile/pages/tasks.md) 与
> [daemon/docs/scheduled-tasks.md](../../../../daemon/docs/scheduled-tasks.md)。

桌面端只写与移动端的差异：

- **入口**：最左 48px 活动栏的「定时任务」图标，以及命令面板 / `⌘2`。
- **范围**：**全局**——列出所有工作区的任务，不只是当前工作区。移动端仍按当前工作区展示。
- **布局**：任务页占满活动栏右侧（**不显示会话栏**）；页内左右分栏——左列任务列表（约 320px），
  右侧详情；同屏可见，无 push。
- **分组**：左列按工作区分组，组头可折叠（默认展开），显示工作区名 + 任务数；当前工作区置顶，
  其余按工作区顺序，未知 / 已删除工作区排最后并标注。组内启用任务优先，再按下次运行时间升序。
- **列表行**：名称、状态（圆点 + 文案）、`计划 label · 下次`、执行目标（会话 / 命令）与 AI 创建标记。
  选中态与会话列表一致：`surface-2` 灰胶囊（圆角 10），**不加彩色左条**；不用整块主色。
- **详情**：标题（所属工作区 chip +「完全权限」徽章）+ 状态网格 +「执行指令」+「执行历史」三段共用一条左线；
  指令超过 8 行默认折叠，可展开 / 复制；历史有列头，状态用中文（成功 / 已中断 / 失败），
  「查看会话」是行尾链接。动作：立即运行（主按钮 `primary-fill`，品牌青绿 + 深墨字）/
  启停 / 编辑 / 删除（与其余用分隔线隔开）。
  最近 20 次 run；命令输出直接展示在 run 下方。「立即运行」请求期间显示「启动中…」并禁用；
  `lastStatus == running` 时显示「运行中…」并禁用，详情每 5s 轮询直到 run 结束。
- **新建**：「新建任务」先弹确认框，框内选择**目标工作区**（默认当前工作区，停用的不可选）；
  确认后调用 `POST /api/scheduled-tasks/config-session`，在主区切到该配置会话（必要时自动切换工作区）。
  AI 只问用户想完成什么任务，执行 prompt 由 AI 起草并展示确认，不让用户写 prompt。
  每 workspace 复用一份配置会话。
- **编辑**：居中模态（复用 `NewSessionDialog` 的 `.modal` 样式），可改名称、执行指令 / 命令、
  结构化计划；类型不可改。AI 任务的目标会话可改（已有会话 / 下次运行新建会话），
  下次触发生效；`command` 任务不可改绑。原始 cron 任务只允许改名称和内容。
- **刷新**：页面可见时每 20 秒静默轮询；任何变更后立即刷新。不新增 stream/IPC：
  REST 走通用 `request`，`preload-sandbox` / `protocol-purity` 边界不变。
- **快捷键**：`⌘2` 打开全局任务页；命令面板同样可进入。
