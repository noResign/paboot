# ② 会话列表（Conversation List）— 桌面

> 索引与全局规范见 [../design.md](../design.md)。移动端原页：`docs/ui/mobile/pages/sessions.md`
> ——**内容模型沿用，本文件只写桌面差异**。

### 6.2 ② 会话列表（Conversation List）→ **左栏**

移动端这里是一整个 Tab（底部导航第一项）；桌面端它**收进左栏常驻**，因为桌面端最该做的是
「同屏」：不切页就能看到哪个会话在跑、哪个在等我。这也是桌面端相对手机端最大的结构性增益。

**关键元素**：

1. **左栏顶部**（三行，从上到下）：
   - **连接切换器**：`▾ 我的笔记本（本机） ● 已连接 / 家里的台式机 ○ 未连接 / ＋ 添加电脑…`。
     选中项决定左栏、主区、Workspace 列表的作用域（技术方案 §4）。
   - **Workspace 切换器**（沿用移动端：当前名/path，点击进工作区管理）。
   - **`[+ 新建会话]`（`⌘N`）**。
2. **会话列表**，`只展示当前 Workspace 的 Session`，**按「要不要我动手」分组，其余按时间倒序**：

   `⚠ 等待我处理`（`warning`） → `✗ 失败`（`error`） → **其余会话**（`lastActiveAt` 倒序）

   - 桶顺序**固定**，桶内才按 `lastActiveAt` 倒序；每桶一个可折叠段头带计数
     （`⚠ 等待我处理 (2)`）；**默认只展开前两个桶**。
   - 理由：桌面端的核心价值是「不切会话就知道谁在等我」。纯时间序会把一个 3 分钟前完成的
     长会话盖在正在等我审批的会话上面。
   - 🔴 **只有「要我动手」的状态才单独成桶**。「运行中」曾经也是独立一桶，但它不提供额外信息
     ——运行中的行本来就有脉冲圆点 + 左边框，单独成桶只是把「不需要我管的会话」劈成两个列表。
     规格里原第 4 个桶「需注意」同理删掉：它的判定条件从来没有定义过。
   - **这与移动端的「按 cwd 子目录分组」是两个正交的轴**：桌面以**状态**为主轴，cwd 降级为
     行内小字或筛选器。移动端的 cwd 分组保持不变。
3. **会话行**（密度远高于移动端卡片）：
   - 双行：标题（`title`，无则「未命名会话」）+ `Agent 徽章 · 相对时间`；行高 44–48。
   - 状态列：`等待我处理` 左侧 6px `warning` 竖条 + 角标 `N`；`运行中` 用 `primary` 脉冲圆点 + 左边框。
   - **hover**：整行 `primary-subtle`，右侧露出 `重命名` / `删除` 两个图标按钮
     ——**替代移动端的长按弹删除**（桌面长按是反常交互）。
4. **左栏底部**（固定）：`📁 文件`、`⚙ 设置` 两个入口 + `● N 个任务运行中`（有任务时才出现，
   点击展开运行中列表并可跳转）。
5. **空态**：插画 +「还没有会话」+「新建会话」（沿用）；桌面加一句「或从别的电脑连接一个
   daemon」（有保存过的远程连接时）。

**交互**：
- 点击行 → 主区切到该会话的聊天（**不 push、不切页**）。
- hover 露出操作；**右键菜单**：重命名 / 删除 / 复制 cwd / 在新窗口打开（🟡 M3）/ 标记已读。
- 删除走确认框（沿用移动端文案与 `DELETE /api/sessions/:id`）。
- **刷新 `⌘R`**，并在左栏头部放一个刷新图标（低频、hover 才显形）；**不再有下拉刷新**。
- 切换连接：**必须先退订旧连接的所有流**再建新连接（否则已死 daemon 的帧会混进来），
  然后重拉会话/工作区列表（技术方案 §4）。

**状态**：
- 加载中：骨架屏（左栏窄，用 3–4 条灰条）。
- 空态 / 错误态：沿用移动端文案；连接层错误（token 失效、地址变了）同时给「重新连接」入口（→ §6.1）。
- `workspace_not_found`（本地选中的工作区在 daemon 上已不存在）：不报错，清掉本地选择、
  按「不过滤」重拉——否则会停在一个永远重试不好的错误页（沿用移动端这条）。
- 会话若正由**另一台设备**驱动：行上仍显示「运行中」，进会话后主区会说明「该会话正由其他设备
  驱动」（§6.3），但**不做实时推送**——左栏的运行中标记来自常规轮询（技术方案已定 20）。
  实现：连上后每 **5 秒**静默拉一次 `GET /api/sessions`（不置 `loading`，否则列表每 5 秒闪一次
  骨架屏）。窗口收进托盘也照拉——tray 的运行数、左栏底部「N 个任务运行中」都吃这份数据。

> ⚠️ 数据现状：`GET /api/sessions` **没有**最后一条消息预览（移动端已知），桌面同样只用
> 标题 / 时间 / 运行态。分桶所需的 `等待我处理` 来自本客户端已收到的审批帧 + 轮询到的
> `running`；它不是 daemon 提供的字段。
