# ⑬ 记忆（Memory）— 桌面

> 索引与全局规范见 [../design.md](../design.md)。入口在「个人空间」工作区概览。
> M1：记忆 / 时间线 / 搜索 tab；M2 增加重复与实体 tab；D38 增加跟进 tab 与单条反馈。
> workspace 记忆开关与画像只读展示在这里，记忆模型选择仍在 ⑧ 设置 → 模型 Provider。

## 目的

在较高密度下浏览、核对和纠正长期个人记忆，而不是把每条记忆的所有细节都铺在列表里。

## 入口

- 工作区概览 →「记忆」信息卡 → 全屏 overlay（`kn-panel`）。
- 没有选中会话时也可从概览进入；关闭回到概览。

## 布局

顶部工具条：`记忆 / 时间线 / 搜索 / 跟进 / 待裁决 / 重复 / 实体` 七个 tab；右侧是 workspace 记忆开关
（启用 / 注入；life 显示画像 off/portable/full，dev 显示 lifeReadable），改动即时保存。

左右双栏（记忆 tab）：

1. **左栏（320–390px）**
   - 顶部状态行：`自动整理 / 配置不可用 / 仅记录` + 模型 id + 待整理数。
   - 未选模型时提示到「模型 Provider」勾选「用于记忆」；已选但 Key/启用状态失效时显示「配置不可用」。
   - 搜索框：匹配摘要、内容、predicate、来源原话。
   - 分组列表：`关于你(fact)` / `偏好(preference)` / `关系(relation)` / `画像(profile)`。
     - 分组头显示箭头 + 名称 + 数量；可折叠，默认展开。
     - 空分组不渲染；无匹配时显示「没有匹配的记忆」。
   - **紧凑行**：摘要最多 2 行 + 权威标记（你已确认 / 自动整理）、来源 scope 标记
     （`全局` / 工作区名 / `个人空间`，仅跨 scope 读取时显示）、私密标记、相对时间。
     详情头部始终展示来源 scope。
     M0 行内不放开来源和按钮。
   - 排序：`user_confirmed` 优先，其次 importance，再按 updatedAt 倒序。
   - 首次加载默认选中第一条；刷新后保持选中，选中项消失则回退到第一条。
2. **右栏（详情）**
   - 徽章：类型 / 权威 / 私密 + `#claim_xxxx`。
   - 标题：`summary`；内容与摘要不同时展示 `objectText`。
   - 指标：置信度、重要度、更新时间、有效期。
   - 来源原话：逐条 quote；“没有来源”时明确提示。
   - 操作：`改正`（内联表单）/ `忘记`（二次确认）；life 记忆额外提供
     `提升为全局记忆`（portable / personal / life_only）。
   - 反馈行：`有用` / `过时了` / `不准确`（`不准确` 二次确认）。标记后该条不再注入 / 召回，
     但不会被删除；只对当前 scope 自己的记忆显示。
   - 未选中时显示空态，提示从左侧选择。
3. **时间线 tab**：左栏 observation / summary 紧凑行；右栏标题、副标题、相关文件。
4. **搜索 tab**：服务端 D31 搜索；结果带类型、文件数、文档路径，点击看摘要 / 文件列表。
5. **待裁决 tab**：同一事实的新旧冲突；左右展示双方内容，操作 `以新为准` / `以旧为准`。
   保留方标记为 `user_confirmed`，另一方归档。
6. **重复 tab**：Tier-1 待审候选；两侧摘要 + 相似度 + 方法，操作 `合并` / `不是重复` / `忽略`。
   `user_confirmed` 优先，合并后重复项归档。
7. **跟进 tab**：`nextSteps` 生成的 open loop，以及摘要比对后判定的「可能已完成」候选。
   候选行标黄并提供 `确认完成` / `仍在进行`，未完成行提供 `标记完成`；tab 上的角标是候选数。
8. **实体 tab**：按 kind 分组（人物 / 地点 / 组织 / 宠物 / 项目 / 事物），左栏行显示规范名、
   别名数、关联记忆数；右栏展示别名与计数，可从同 kind 的其他实体中选择目标合并。
   合并前二次确认（来源归档、记忆改指向），成功后刷新实体与记忆列表。
   左栏可切换到「已合并」，查看归档实体并撤销合并（恢复 claim / 别名 / link）。
   life 视图的实体详情展示「跨 scope 关联」，可关联到 `user` scope 的同 kind 实体或解除关联；
   不同 scope 的自动化 link 只发生在 `user` ↔ life。

## 状态

- 加载中：左栏 `加载中…`。
- 无记忆：图标 +「还没有记忆」+ 在个人空间里聊天的提示。
- 错误：左栏错误条；改正 / 忘记失败保留当前选中和表单。
- 改正成功：提示「已改正」，刷新列表，保持选中。
- 忘记成功：提示「已忘记」，刷新列表，选中回退。

## 边界

- 不提供新建 / 手动编辑来源；新建记忆留给后续阶段。
- 不展示 `secret`（服务端不入库 / 不注入）；`private` 在 life 中正常展示并带标记。
- 设置「用于记忆」的模型属于 Provider 设置，不放在本页。
