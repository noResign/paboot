# ⑦ 设置（Settings）— 桌面

> 索引与全局规范见 [../design.md](../design.md)。移动端原页：`docs/ui/mobile/pages/settings.md`
> ——**分组与文案沿用；本文件写桌面差异，并把移动端的 ⑧⑨⑩ 三页并进来**（移动端把它们收在同一个
> 文档里，桌面沿用同一处）。

### 6.7 ⑦ 设置（Settings）→ **主区**

**目的**：连接、工作区、默认偏好、通知、外观、更新、关于。（同移动端。）

**形态差异**：移动端是 Tab；桌面占满主区，并改为**左侧小节导航 + 右侧内容**——桌面设置页的标准
形态，避免一长条滚动。小节的**顺序与命名沿用移动端的设置分组**。小节选中用 `surface-2` 底 +
2px `accent-bar` 左边条，和会话/文件/任务列表同一套，不用整块主色。

**各小节（桌面差异 + 新增）**：

- **连接**：服务器地址默认完全隐藏（显示 `••••••••`），行内眼睛图标显示完整 `host:port`；
  名称可用铅笔图标内联编辑（Enter / 失焦保存，Esc 取消），同时更新连接配置与最近连接；
  token 只显示是否持有与来源，不回显值。
  未命名时显示「未命名」；标题栏连接胶囊同样名称优先、回退到地址。桌面新增 **「本机 daemon」**
  区块 → §6.6（状态摘要 + 进入管理页）。另有「启动应用时自动启动本机 daemon」偏好（默认开）：
  已保存 / 已运行的连接总是优先，上次选中的远程不可达时不会被本机 daemon 顶替。
- **工作区**：打开 **6.2a 工作区概览**（主目录 / 附加目录 / 最近会话）；重命名 / 删除 / 导入导出 → 见下 §6.9。
- **助手**：工作区级 agent 定义的管理页（列表 / 新建 / 只读开关 / 删除）→ §6.7.1。
- **默认偏好**：默认 Agent（🟡）、新建 Session 的默认权限模式（乐观更新 + 失败回弹，沿用）。
- **通知**：桌面用**原生通知 + 托盘**，不是 Android 通知频道。保留总开关（默认开）。
  新增两项桌面专有：
  - 「审批提醒是否抢焦点」（**默认不抢**，见 §6.5）。
  - 「关闭窗口时：最小化到托盘 / 退出应用」——**不能默默替用户决定**（§7.4），首次关闭时提示一次。
- **外观**（🟡 桌面新增）：**主题三态**（浅色 / 深色 / 跟随系统——移动端只有跟随系统 + 手动）、
  界面缩放（90%–150%，`⌘+/−/0`）、「重置左栏宽度」。
- **关于**：App 版本、**daemon 版本**（`GET /api/health`）、Electron/Chromium 版本、许可证。

### 6.7.1 助手（Agent 管理）🟢 已实现（2026-11-23）

**入口**：设置左栏「助手」，位于「工作区」与「模型 Provider」之间。它管理的是**工作区级**的
agent 定义，不是某个会话的成员。

**工作区**：有多个工作区时标题右侧有下拉（与工作区概览同一份列表）；整页内容按所选工作区过滤。
**空态**：虚线卡片「还没有助手 / 在下面创建一个，或添加远端助手。」

**布局**：标题 + 说明 → `添加远端助手` 工具条（点开是内联表单卡）→ 助手卡片列表 → 新建助手卡。

**列表项**（每行一张卡片）：
- 头部：名字 + 徽标 + 右侧操作。徽标：`默认`（隐式替身）、`远程助手`（peer）、`外部 CLI`（heavy）、
  `已停用`、`当前离线`（enabled 但 `online=false`）。
- 简介（简介为空时回退显示 backend；非编辑态附带 `只读 / 可写`）。
- 底部机制行（仅非隐式 agent）：`只读（不改代码）` 复选框（就地 PATCH）在左，`删除` 在右。
- 本地 agent 操作：`共享 / 收起共享`、`编辑`；peer 操作：`探活`、`断开`。
- 隐式 agent（会话的默认替身）不出现在列表里。

**新建**（底部独立卡片）：
- 第一行：名字（≤40 字，必填，单行）与 runtime 选择并排（runtime 靠右，不可用置灰）；
  下一行是简介（≤40 字，单行；同时展示给用户与同房间其他 agent 的名册）。
- **定义**（≤20000 字，多行文本域，可选）：这个助手自己的系统提示，写它是谁、该怎么工作；
  **不进入房间名册**。创建与编辑都可改。简介保持一句话，长内容放这里。
- runtime 选择：`内置（无需 CLI）` 在前，其余来自 `GET /api/agents`；不可用的置灰。
- **「只读」默认勾选**：只读 agent 不挂 Write/Edit，Bash 只放行只读白名单；
  一个房间最多一个可写 agent。
- 文案必须写明：**创建后不会自动进入任何会话**——在会话里用 `@` 点名，它才会加入那个房间。

**接口**：`GET|POST /api/workspaces/:id/agents`、`PATCH|DELETE /api/agent-profiles/:id`；
列表 DTO 不含机制字段，`只读` 由详情端点提供。新建/编辑后无需刷新整个设置页。

### 6.9 ⑧⑨⑩ 工作区管理 / 目录选择器 / 会话权限

移动端把这三者放在设置文档里，桌面沿用同一处。**内容全部沿用，只写桌面差异。**

**⑧ 工作区管理**

> 与 **6.2a 工作区概览** 分工：概览看目录 / 最近会话；管理做重命名 / 删除 / 导入导出。

- 列表内容沿用：名称、主目录、附加目录（`dirs`）、浏览书签（`shortcutDirs`，**不授予任何权限**）、
  `sessionCount`、启用开关；操作行三个固定按钮（启用/禁用、重命名、+ 附加目录）。
- **工作区记忆总开关**：每张工作区卡片底部有一行「工作区记忆」勾选框，旁边一行说明当前状态
  （`默认关闭` / `已启用：捕获并注入到新会话` / `已启用：只记录，不注入`），读写
  `GET|PATCH /api/workspaces/:id/memory`，改动即时保存。它和 ⑬ 记忆面板顶部工具条右侧的开关是
  **同一个设置**——面板是「看记忆」的地方，开关放在这里才符合「工作区级设置」的位置；
  个人空间不出现在本列表（不可删/停用），它的开关仍在记忆面板里。
  **关闭 = 不再捕获与注入，已有记忆仍可查看与忘记**（见 ⑬ 与 `daemon/docs/memory.md` §6）。
- **删除**：移动端是「左滑露出删除」，桌面改为 **hover 露出删除按钮 + 右键菜单**。
  删除确认框内容与规则**完全沿用**（含「同时删除 N 个会话」勾选、`?cascade=1`、
  附加目录的唯一入口在这里）。**任何添加的工作区都可删**——删默认工作区时 daemon 会把默认落点
  交给另一个启用的工作区，没有就交给内置「个人空间」工作区。个人空间**始终出现在列表/切换器里**，
  但不可删除或停用。
- **打开时的工作区**：桌面按 daemon 身份（`serverId`）在本地记住上次选择，下次打开直接落回它；
  没有记忆或记忆已失效时用 daemon 默认。手机上同样由 `WorkspaceSelection` 本地持久化。
- **同时恢复会话**：每个工作区在本地记住最后打开的会话（含 host/工作区两个维度），切换 host
  或重启后等会话列表加载完自动打开；记录失效（会话已删/已不在当前工作区）就静默清掉。

**⑨ 目录选择器**

- 内容沿用：路径输入、**只列文件夹**、已注册目录标注「已是工作区」、底部「选择此文件夹」
  （已是工作区时禁用）、`/` 与 `~` 的二次确认、安全提示「workspace 不是沙箱」。
- 视觉：比通用 modal 更宽；目录行用统一线性文件夹图标 + 浅色图标底，不再用平台 emoji；
  路径输入、目录列表和底部说明分区，列表行 hover 时才露出进入箭头。
- **桌面增强**：支持**直接输入绝对路径**回车跳转（桌面用户更愿意打字）。
- 复用点：这是**同一个组件**被两处使用——⑨ 新增工作区、⑧ 加附加目录/书签。启动本机 daemon
  固定进入内置「个人空间」工作区，不再打开目录选择器。

**⑩ 会话权限设置**

- 内容**完全沿用**：三档（`ask` / `acceptEdits` / `bypass`）+ per-runtime 文案、
  已授权工具列表（grants）+ 撤销、全部撤销、`bypass` 下 grants 显示「已暂停」、以及三条说明文案。
- 形态：从会话副信息行的权限模式按钮（或标题栏「⋯ → 会话权限」）进入，桌面用**模态**（移动端是 push 子页）。
- 🔴 **补一句跨设备作用域**（相对移动端的新要求）：「允许全部」写的是 **Session + toolName**，
  grant 存在 daemon 上所以**其他设备看这个会话时同样免问**（§6.5 的多端小节）。撤销只影响后续请求。

**状态**（三页共同）：加载中骨架；写操作乐观更新 + 失败回弹并提示；409 类冲突
（`workspace_not_empty` / `workspace_is_default` / `dir_exists` / `shortcut_exists` /
`workspace_disabled`）沿用移动端的文案映射。
