# ⑦ 设置（Settings）— 桌面

> 索引与全局规范见 [../design.md](../design.md)。移动端原页：`docs/ui/mobile/pages/settings.md`
> ——**分组与文案沿用；本文件写桌面差异，并把移动端的 ⑧⑨⑩ 三页并进来**（移动端把它们收在同一个
> 文档里，桌面沿用同一处）。

### 6.7 ⑦ 设置（Settings）→ **主区**

**目的**：连接、工作区、默认偏好、通知、外观、更新、关于。（同移动端。）

**形态差异**：移动端是 Tab；桌面占满主区，并改为**左侧小节导航 + 右侧内容**——桌面设置页的标准
形态，避免一长条滚动。小节的**顺序与命名沿用移动端的设置分组**。

**各小节（桌面差异 + 新增）**：

- **连接**：服务器地址、token（只读掩码）、「重新连接」→ §6.1。桌面新增 **「本机 daemon」**
  区块 → §6.6（状态摘要 + 进入管理页）。
- **工作区**：→ 见下 §6.9。
- **默认偏好**：默认 Agent（🟡）、新建 Session 的默认权限模式（乐观更新 + 失败回弹，沿用）。
- **通知**：桌面用**原生通知 + 托盘**，不是 Android 通知频道。保留总开关（默认开）。
  新增两项桌面专有：
  - 「审批提醒是否抢焦点」（**默认不抢**，见 §6.5）。
  - 「关闭窗口时：最小化到托盘 / 退出应用」——**不能默默替用户决定**（§7.4），首次关闭时提示一次。
- **外观**（🟡 桌面新增）：**主题三态**（浅色 / 深色 / 跟随系统——移动端只有跟随系统 + 手动）、
  界面缩放（90%–150%，`⌘+/−/0`）、「重置左栏宽度」。
- **关于**：App 版本、**daemon 版本**（`GET /api/health`）、Electron/Chromium 版本、许可证。

### 6.9 ⑧⑨⑩ 工作区管理 / 目录选择器 / 会话权限

移动端把这三者放在设置文档里，桌面沿用同一处。**内容全部沿用，只写桌面差异。**

**⑧ 工作区管理**

- 列表内容沿用：名称、主目录、附加目录（`dirs`）、浏览书签（`shortcutDirs`，**不授予任何权限**）、
  `sessionCount`、默认标记、启用开关；操作行四个固定按钮保留。
- **删除**：移动端是「左滑露出删除」，桌面改为 **hover 露出删除按钮 + 右键菜单**。
  删除确认框内容与规则**完全沿用**（含「同时删除 N 个会话」勾选、`?cascade=1`、默认工作区不可删、
  附加目录的唯一入口在这里）。
- 🔴 **注意「默认工作区」的连带含义**：默认工作区不可删除，要删得先设别的为默认。这与
  技术方案已定 23（托管 daemon 首次启动锁定默认工作区）是同一件事的两面——桌面端比移动端更该
  把这条讲清楚，因为用户可能刚在「启动本机 daemon」时随手选了个目录。

**⑨ 目录选择器**

- 内容沿用：面包屑、**只列文件夹**、已注册目录标注「已是工作区」、底部「选择当前文件夹」
  （已是工作区时禁用）、`/` 与 `~` 的二次确认、安全提示「workspace 不是沙箱」。
- **桌面增强**：支持**直接输入绝对路径**回车跳转（桌面用户更愿意打字）。
- 复用点：这是**同一个组件**被三处使用——⑨ 新增工作区、⑧ 加附加目录/书签、
  以及 §6.1「启动本机 daemon」时选 `--workspace`。

**⑩ 会话权限设置**

- 内容**完全沿用**：三档（`ask` / `acceptEdits` / `bypass`）+ per-runtime 文案、
  已授权工具列表（grants）+ 撤销、全部撤销、`bypass` 下 grants 显示「已暂停」、以及三条说明文案。
- 形态：从聊天标题栏 ⚙ 进入，桌面用**模态**（移动端是 push 子页）。
- 🔴 **补一句跨设备作用域**（相对移动端的新要求）：「允许全部」写的是 **Session + toolName**，
  grant 存在 daemon 上所以**其他设备看这个会话时同样免问**（§6.5 的多端小节）。撤销只影响后续请求。

**状态**（三页共同）：加载中骨架；写操作乐观更新 + 失败回弹并提示；409 类冲突
（`workspace_not_empty` / `workspace_is_default` / `dir_exists` / `shortcut_exists` /
`workspace_disabled`）沿用移动端的文案映射。
