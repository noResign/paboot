# ⑤ 文件 / ⑥ Diff（Files & Diff）— 会话右栏

> 索引与全局规范见 [../design.md](../design.md)。移动端原页：`docs/ui/mobile/pages/files.md`
> ——**内容模型与配色沿用，本文件只写桌面差异**。

### 6.8 ⑤ 文件（Files）/ ⑥ Diff → **会话右栏**

**目的**：看这个 Workspace 里改了什么、以及任意文件的内容与改动。（同移动端。）

**入口**：会话标题栏的「文件」按钮 → 右侧展开文件栏。左栏**不再有文件入口**，主区也没有
独立的文件页；文件浏览围绕当前会话/Workspace 进行。

**形态差异：默认「列表 → 详情」下钻，右栏够宽才两级分栏。**

- **默认（窄右栏）**：目录栏（改动文件树 / 全部文件树）占满右栏。点开文件后**列表让位**，
  整栏显示 diff 或文件内容，左上角 `←` 返回。列表只是被隐藏、**不卸载**，返回时滚动位置、
  展开目录和读取缓存都还在。
- **宽右栏（≥ 680px）**：自动变成「目录栏 200px + 内容」两级分栏，点别的文件只换右半边。
- **右栏没有自己的标题栏**：控件跟着它控制的那一半走——列表头是「改动 / 全部文件」+ 刷新 + 关闭，
  内容头是路径 + 状态 + `+增/−删` + 并排/统一 + 返回/关闭。多一层 44px 的「文件 ✕」只是多一行 chrome。
- 右栏默认 420px（320–880 可拖拽）。**并排 / 统一始终可选，不按宽度隐藏或禁用**：窄栏下
  选并排就是两条会横向滚动的列，由用户自己决定，而不是控件随宽度出现/消失。
  这个选择**记进外观偏好**（localStorage），收起文件栏再打开沿用；默认统一。
- **宽度上限随窗口收敛**：始终给聊天列留 560px；窗口小到连 420 都放不下时，左栏让位。
  **聊天列收起时右栏占满主区，分栏按面板的实际宽度判断**（不是记住的 420）——否则收起聊天
  专心看文件时，明明很宽却不会分成两栏。

```
右栏（默认，窄）                右栏（宽，两级分栏）
├─ 列表（占满）                 ├─ 目录栏 200px
└─ 选中后：内容（占满，← 返回）   └─ 内容（其余宽度）
```

为什么默认下钻：默认窗口 1280–1440 里「左栏 300 + 聊天 760 + 右栏 420」已经超出窗口宽度，
再让目录栏常驻 200，聊天就掉到不可读的宽度。移动端只能 push，桌面在宽屏上才换成分栏——**同屏是
增益，不是前提**。

> 旧实现是「点开文件就把右栏拉到 520 + 200px 目录列」，结果 diff 只剩 320px、每行都被切。
> 现在的宽度只决定**列表/内容怎么排**（下钻或分栏），不决定 diff 用哪种视图。

**沿用移动端的部分**（不重复）：

- **分段控制**：改动 / 全部文件；
- **根切换**：Workspace 各根（主目录 + 附加目录）+ **浏览书签**（`shortcutDirs`，只多一个 tab、
  **不授予 agent 任何权限**）；
- **面包屑**、分页（`limit` 上限 500）、搜索、`showHidden` / `showIgnored` 开关；
- **Diff 的两种视图**（并排 / 统一）与 **IDE 深色配色**；
- **文件内容查看器**（`MAX_CONTENT_BYTES` = 1 MiB 上限，超限的处理沿用）；
- 二进制/大文件不预览、只给下载/另存（沿用）。

**桌面差异**：

- **改动 Tab 只显示改动文件树**，不再提供「全部 diff」的堆叠视图；点文件在右侧看该文件的改动。
- **并排 Diff 可选，不是默认**：默认统一视图，随时可切并排；窄栏下并排横向滚动，
  不自动降级、也不自动拉宽右栏。
- **文件树 hover / 右键菜单**：复制路径 / 在 Finder/Explorer 中显示（🟡）/ 查看 diff。
- **`⌘F` 在文件内容里搜索**（移动端是页面内搜索）。
- **媒体预览**沿用 `paboot-media://` 自定义协议（技术方案 §1：主进程注入 token，支持 Range）；
  桌面还可加「另存为」（🟡）。
- 右栏只显示**当前的最终改动**（工作区实时状态）；不提供按 run 筛选。每轮改动的查看与回滚
  在对应消息气泡上操作。
- 右栏宽度可拖拽，且随会话/Workspace 切换清空文件树与选中文件——不串上一台的路径。

**状态**：

- 不是 git 仓库 → 改动 Tab 显示「此目录不是 Git 仓库」，全部文件 Tab 照常（沿用移动端分支）。
- 空改动 / 空目录 / 读取失败（权限、消失）→ 沿用移动端的文案与重试。
- 大文件、二进制 → 沿用「不预览、给路径与大小」的处理。
- 加载中：文件树与内容各自骨架；内容区切换文件时保留上一份的骨架而不是空白（桌面观感）。
