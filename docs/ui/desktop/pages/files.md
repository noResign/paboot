# ⑤ 文件 / ⑥ Diff（Files & Diff）— 桌面

> 索引与全局规范见 [../design.md](../design.md)。移动端原页：`docs/ui/mobile/pages/files.md`
> ——**内容模型与配色沿用，本文件只写桌面差异**。

### 6.8 ⑤ 文件（Files）/ ⑥ Diff → **主区（两级分栏）**

**目的**：看这个 Workspace 里改了什么、以及任意文件的内容与改动。（同移动端。）

**整体属于 M3**（右栏面板与多窗口同批）。但这里列出的**结构决定**要从第一版就按它写，
否则 M3 会变成重构。

**形态差异：移动端「列表 → push 查看」，桌面「同屏两级分栏」。**

```
主区
├─ 文件树（左，可调宽，240–400）/ 或「改动」列表
└─ 内容（右）
     ├─ ⑥ Diff 查看器
     └─ 文件内容查看器 / 媒体预览
```

移动端因为窄屏只能「点进去看」；桌面有横向空间，**文件树与内容必须同屏**——这是 Diff 体验
在桌面上最大的增益，也是这页存在的意义。

**沿用移动端的部分**（不重复）：

- **分段控制**：改动 / 全部文件；
- **根切换**：Workspace 各根（主目录 + 附加目录）+ **浏览书签**（`shortcutDirs`，只多一个 tab、
  **不授予 agent 任何权限**）；
- **面包屑**、分页（`limit` 上限 500）、搜索、`showHidden` / `showIgnored` 开关；
- **Diff 的两种视图**（并排 / 统一）与 **IDE 深色配色**；
- **文件内容查看器**（`MAX_CONTENT_BYTES` = 1 MiB 上限，超限的处理沿用）；
- 二进制/大文件不预览、只给下载/另存（沿用）。

**桌面差异**：

- **并排 Diff 成为默认视图**（移动端默认统一视图，因为窄屏）；统一视图作为可切换项。
  但**并排只在窗口够宽时提供**：宽度不足时**自动降级为统一视图**并把并排选项置灰
  （paseo 就是这么做的：`canUseSplitLayout = isWeb && !isCompact`，窄了静默降级）。
  别让并排在窄窗里挤成两条 40 字符宽的窄条——那比统一视图更难读。
- **文件树 hover / 右键菜单**：复制路径 / 在 Finder/Explorer 中显示（🟡）/ 查看 diff。
- **`⌘F` 在文件内容里搜索**（移动端是页面内搜索）。
- **媒体预览**沿用 `paboot-media://` 自定义协议（技术方案 §1：主进程注入 token，支持 Range）；
  桌面还可加「另存为」（🟡）。
- **右栏面板（🟡 M3）**：把「本会话改动的文件 / 待办 / 已授权工具」并到聊天右侧，边看回复边看
  改了哪些文件（§2 的可选右栏）。

**状态**：

- 不是 git 仓库 → 改动 Tab 显示「此目录不是 Git 仓库」，全部文件 Tab 照常（沿用移动端分支）。
- 空改动 / 空目录 / 读取失败（权限、消失）→ 沿用移动端的文案与重试。
- 大文件、二进制 → 沿用「不预览、给路径与大小」的处理。
- 加载中：文件树与内容各自骨架；内容区切换文件时保留上一份的骨架而不是空白（桌面观感）。
