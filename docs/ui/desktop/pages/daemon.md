### 6.6 ⑥ 本机 daemon 管理（Daemon）🖥 桌面独有

**目的**：让用户看清「本机 daemon 现在什么状态、谁在管它」，并在是**我们启动的**时候能启停/看日志。

**入口**：设置页的「本机 daemon」区块 → 或标题栏下方 daemon 状态条的点击（§5 组件表）。

**关键元素**（主区整页）：

```
本机 daemon
────────────────────────────────────────────────────────
状态      ● 运行中（本应用托管）
版本      v1.8.0
地址      127.0.0.1:4780
工作区    ~/Projects
数据目录  ~/.paboot
手机访问  ○ 关闭（仅本机）          [ 开启… ]

[ 重启 ]  [ 停止 ]  [ 复制 token ]  [ 改 token ]
────────────────────────────────────────────────────────
日志  ▾                              [ 自动滚动 ] [ 清空 ]
[2026-10-08T00:18:54] INFO  paboot 1.8.0
[2026-10-08T00:18:54] INFO  bound to 127.0.0.1:4780
[2026-10-08T00:18:55] INFO  claude: v2.x (authenticated)
```

**🔴 能力按「谁在管」分档**（技术方案 §4 的表）：

| 能力 | 本应用 spawn 的 | 本机但外部（systemd / 别人的） | 远程 |
|---|---|---|---|
| 看状态 / 版本 / 地址 / 日志 | ✅ | ✅（日志仅我们能捕获到的：附着的拿不到 → 置灰） | 只读状态 |
| 重启 / 停止 | ✅ | ❌ **置灰** + 说明「由 systemd 管理，请在系统层面操作」 | ❌ |
| 手机访问开关 | ✅ | ❌ 只读显示探测到的绑定 | ❌ |
| 改 token | ✅（写文件 + 重启） | ❌ 置灰 | ❌ |

- **不去 shell out `systemctl`**：那是部署流水线的活，会打架。可以额外做一个显式的
  「检测服务」动作，给出 `paboot.service` 的提示（不做则已，做要在用户点之后才执行）。
- 远程 daemon 这一页退化成**只读的状态卡**（版本/地址/延迟），不给任何按钮。

**「手机访问」开关** = 托管子进程的 `--host`（`127.0.0.1` ↔ `0.0.0.0`），🔴 **安全相关**：

- 开启时是**显式确认**（模态 + 风险说明 + 展示局域网地址与 token 的二维码/复制），
  **不是静默切换**。理由：绑 `0.0.0.0` 等于在局域网里开了一个「单个静态 token 背后的、
  带 shell 权限的 RCE 端点」。
- 关闭时也要说清后果：「手机将无法连接」。
- 非托管 daemon 上这一行只读显示探测到的绑定（本机 systemd 是 `0.0.0.0`，所以显示「开放中」）。

**「改 token」** = 重写 `<data-dir>/token` 并**重启托管 daemon**——daemon 只在启动时读一次 token，
不重启就不生效，所以「改了没用」的错觉必须靠重启避免：

- 只对**本应用托管的** daemon 开放；systemd / 手动的改完没法生效，一律置灰（与停止/日志同一档）。
- 输入留空 = 随机生成 32 字节 hex；也可粘贴自定义值（8–512 个可见字符、不含空格）。
- 🔴 改 token **等于换掉远程 shell 的钥匙**：所有已连接客户端（手机、别的电脑）立刻失效，必须重新输入新 token。
  所以要有**二次确认**（重启还会中断正在跑的任务），改完把**新 token 显示出来**（可复制）——否则用户拿不到刚设的凭据。

**日志面板**：等宽、跟随主题、`INFO/WARN/ERROR` 按语义着色（`text-secondary`/`warning`/`error`）、
主进程 5000 行环形缓冲、按 100ms 批量推给渲染层、可复制、可导出（🟡）。
**绝不把原始栈抛给用户**——supervisor 捕获的 stderr 走人话提示（技术方案 §2）。

**spawn 相关**（M4；但设计上现在就要留位）：

- 首次「启动一个本机 daemon」要**先选工作目录**——`--workspace` 在首次启动就锁定了默认工作区
  且**不可删除**，而它是 agent 的写入边界（技术方案已定 23）。选完再问「手机访问」。
- **端口冲突**不在这页做文章：走 §6.1 连接页的发现分支（更早暴露），这页只显示结果。

**状态**：
- 未托管 / 托管停止 / 托管运行中 / 外部托管（只读） / 启动中（显示就绪轮询进度） / 启动失败
  （人话错误 + 「查看日志」）。
- 版本与本 app 内置的 daemon 不一致时（技术方案「版本漂移」）：给一条提示 + 「重启以使用内置版本」，
  **只在托管 daemon 上给**——附着的外部 daemon 永不提示重启。
